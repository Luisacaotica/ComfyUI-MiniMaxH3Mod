# v0.2.6 — RefMod bundles and compact loaders

- Save visual and audio references together in one `.safetensors`: choose `save_layout=bundle` in Master, or pack existing references with **Save H3 RefMod Bundle**.
- Select **All / Visual / Audio** per Loader/Axis slot, with independent modality strengths. Excluded components are not loaded.
- Loader and Axis now start with one visible slot. **+ Add RefMod** reveals more slots, up to eight, with each reference's controls grouped together. Removal clears the slot; connected slots are protected.
- The library recognizes combined files, and Config preserves unselected members. The bundle schema is documented in `BUNDLE_FORMAT.md` for third-party pickers.
- Includes RefMod-only dropdown refresh and clearer effective-setting logs added after v0.2.5.

Existing standalone files and workflow values remain supported. Master still defaults to separate files. Combined version-5 files require a bundle-aware reader.

Restart ComfyUI for the Python changes and refresh the browser for the compact interface.

Bundling does not add voice-to-character binding, audiovisual synchronization, or original-waveform passthrough. Voice transfer remains experimental and failed in previous tests.

Validation: 61 local Python regression tests passed, plus frontend checks for adding/removing slots, connected inputs, legacy workflow restoration, serialization and library selection. The user confirmed the compact interface works in ComfyUI. Full GPU generation quality was not validated for this release.
